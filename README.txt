Boulder Dash Version 1.0, developed by group 9, Nathan Welby,
Adam Bartlett, Davide Belsole, Rhys Evans, Haoyang Qian,
Mohsin Lebdah, Elbu Cheung, Ahsan Mian.

This game should be compiled with Java version 23 and JavaFX
version 23, no additional libraries are required.

Compile with the following command:

javac --module-path /path/to/javafx-sdk/lib --add-modules javafx.controls,javafx.fxml include-all-classes-here.java

Run with the following command:

java --module-path /path/to/javafx-sdk/lib --add-modules javafx.controls,javafx.fxml -cp . Main

Enjoy!
